LinKs is a full-featured real-time chat application. Users can register and log in securely. Once inside, they can create chat rooms or join existing ones, and send messages that appear instantly on everyone's screen — no page refresh needed. They'll see who's online via a live presence indicator, and a typing indicator shows when someone is composing a message. All messages are saved to a database, so chat history loads when you open a room. The app handles multiple users simultaneously across rooms, with each room completely isolated from others. It works fast because recent messages are cached in Redis instead of hitting the database every time.
