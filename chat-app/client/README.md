# LinKsy Chat App

LinKsy is a real-time chat application built using the MERN stack with Socket.IO for instant messaging.

## Features

- Real-time messaging
- Typing indicators
- Read receipts (✓✓)
- Image sharing with Cloudinary
- Redis message caching
- Room-based chats
- Authentication with JWT
- Responsive chat UI

## Tech Stack

### Frontend
- React
- Vite
- Axios
- Socket.IO Client

### Backend
- Node.js
- Express.js
- MongoDB
- Socket.IO
- Redis
- Cloudinary
